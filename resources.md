# Resources

## Skills

- [Caveman](https://github.com/juliusbrussee/caveman) by Julius Brussee — An agent skill that reduces response verbosity and token usage by using terse, caveman-style language.
- [Ponytail](https://github.com/dietrichgebert/ponytail) by Dietrich Gebert — An agent skill that favors minimal code, reuses existing solutions, and avoids unnecessary complexity while preserving validation, security, and testing.
- [Claude Code Harness](https://github.com/Chachamaru127/claude-code-harness) by Chachamaru127 — A collection of agent skills for planning, implementing, testing, and reviewing development tasks through a structured workflow.
- [davidondrej-skills](https://github.com/davidondrej/skills) by David Ondrej — A collection of reusable agent skills for coding, research, content preparation, documentation, and workflow automation.

## Tools

- [Spec Kit](https://github.com/github/spec-kit) by GitHub — An open-source toolkit with structured workflows and reusable templates for specification-driven development with AI coding agents.
- [claudish-to-english](https://github.com/gvzdv/claudish-to-english) by gvzdv — A Claude Code plugin that uses a local or API-backed language model to display plain-language rewrites of assistant messages while preserving the original transcript.

## Books

- [Harness Books](https://github.com/wquguru/harness-books) by wquguru — Two books on harness engineering in Claude Code and Codex, covering execution constraints, context management, permissions, recovery, and multi-agent verification.
- [Claude Cookbooks](https://github.com/anthropics/claude-cookbooks) by Anthropic — A collection of practical notebooks, code recipes, and guides for building with Claude, covering tool use, retrieval, multimodal capabilities, and evaluations.

## Skills for Deutsches Recht

- [Claude für deutsches Recht](https://github.com/Klotzkette/claude-fuer-deutsches-recht) by Klotzkette — An experimental collection of Claude skills for German law, covering employment, corporate, insolvency, data protection, and procedural law.
- [Claude for Legal](https://github.com/anthropics/claude-for-legal) by Anthropic — A suite of agents, skills, and connectors for legal workflows including contract review, privacy, corporate law, employment, and litigation, with scope beyond German law.
- [AI Skills German Law](https://borghei.github.io/AI-Skills-German-Law/SKILLS/) by borghei — A catalog of agent skills for German law and EU compliance, organized by legal practice area.
